Rule: use "⋅" for multiplication and Unicode superscripts only for single-character exponents (10ˣ, e²ˣ, 2ˣ, 10⁻ˣ, 10⁻¹⁹). Fractional/compound exponents must stay in caret form: 10^(x/10), 10^(x/20). "×" is reserved for physical dimensions (paper sizes: A4 = 210 mm × 297 mm).

**Why:** User explicitly rejected superscript-parenthesized fractions like 10⁽ˣ⁄¹⁰⁾ as unreadable (July 2026), after the Sources cleanup task initially used them.

**How to apply:** Any formula strings shown in the Sources table or defining relations — never convert caret fractions to superscript parentheses.
